# SmolVLA 20K 训练与部署结果（2026-08-05）

## 结论

当前 50 条成功 episode 已完成 SmolVLA 20K 微调。训练、四个检查点的离线验证以及部署包复验均限定使用物理 GPU 4。四个候选检查点中，`020000` 在本次固定样本离线比较中表现最好，因此被选为首次真机验证候选模型。

机器人在整个训练和离线验证过程中保持关机；这些结果不能替代首次真机低速、有人看护的验证。

## 数据与训练配置

- 数据格式：LeRobot v3
- Episode：50
- 总帧数：66,497
- 采样率：30 FPS
- 视觉输入：胸部 RGB、右腕 RGB
- 状态：右臂 7 个关节弧度值 + 夹爪二值状态
- 动作：右臂 7 个绝对关节目标 + 夹爪二值目标
- 夹爪约定：`0=打开，1=闭合`
- 训练步数：20,000
- 批量大小：64
- 训练设备：仅物理 GPU 4
- 最终训练 loss：约 `0.004`
- 最终学习率：`2.5e-6`

## 部署包自检

- 部署包内 636 个初始文件均通过大小与 SHA-256 清单复核。
- 从部署包的 `checkpoint` 和相对路径 `vlm` 重新加载后，32 个固定样本的全部指标与打包前一致。
- 在物理 GPU 4 上实际启动 LeRobot gRPC policy server，使用数据集第 0 帧完成握手、模型加载、双路图像与状态预处理、10 步动作推理、反归一化和动作返回；返回形状为 `(10, 8)`，全部数值有限。
- 上述自检不导入 ROS、不连接机器人，也不会发布机器人命令。

## 首次真机参数

首次部署使用独立的保守配置 `servo_controller/config/smolvla_first_rollout.yaml`：

- 策略默认关闭；观察节点连通不等于机器人运动。
- 七轴首次速度限制：`0.10 rad/s`。
- 七轴首次加速度限制：`0.30 rad/s²`。
- 单次模型绝对目标与实时关节状态差超过 `0.25 rad` 时拒绝执行并发布 STOP。
- 状态、动作出现 NaN/Inf、维度错误或明显越界时立即拒绝。
- 夹爪使用 `<=0.35` 打开、`>=0.65` 闭合的迟滞阈值。
- 推理客户端默认观察模式；必须显式调用 `/smolvla/set_enabled` 才会发布动作。

## 明天仍必须完成的现场确认

模型文件与软件参数可以提前准备好，但机器人关机时不能完成以下验证：

1. 推理服务器有线 IP 和端口能被机器人 Ubuntu 访问。
2. 胸部与右腕图像的相机对应关系、方向、裁剪和 30 FPS 与训练数据一致。
3. 当前七轴起始姿态落在训练 episode 的起始姿态包络内，且夹爪处于打开状态。
4. `start` 后机器人不动，`arm` 后仍不执行模型动作。
5. 现场人员手握实体急停，仅开启策略数秒，先验证 STOP、Ctrl+C 和实体急停。
6. 无异常后再进行一次空载、低速、短距离任务 rollout。

没有完成上述现场检查前，不应把策略速度调高，也不应无人值守运行。
