## 6. 阶段 B：Baseline 数据收集与 Q Critic 训练

### 6.1 数据采集目标
使用 Baseline VLA 模型在三种光照条件下自主 rollout，自然产生成功/失败轨迹，用于训练 Q Critic。**严禁遥操采集**，必须让模型暴露其在 OOD 环境下的真实弱点。

### 6.2 训练数据集配比（共 120 条）
为确保 Q Critic 既能学到“完美状态”的高价值锚点，又能充分学习“分布外失败”的低价值特征，训练集按以下固定比例采集：

| 光照条件 | 采集数量 | 预期成功率 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **亮光 (Full)** | 30 条 | ~90%+ | 提供高质量正样本锚点，定义 Q 值上界 |
| **中等光 (Half)** | 60 条 | ~30-60% | **核心区分度数据**，提供最具价值的正负样本对比 |
| **暗光 (Dark)** | 30 条 | ~5-20% | 提供真实 OOD 失败轨迹，定义 Q 值下界 |

### 6.3 采集执行规范
1.  **最大步长限制**：单轮最大时间设为正常完成时间的 3 倍（如 90s），超时自动终止并标记为 `Failure`。
2.  **失败判定**：
    -   超时 / 物体掉落 / 箱子翻倒 → 立即停止记录，标记 `Failure`
    -   硬件故障 / SDK 报错 → 立即停止，标记 `technical_abort`，**该条数据剔除不进入训练集**
3.  **失败后不复位**：失败瞬间立即停止数据记录，**严禁将人工复位 / 机械臂归位过程录入该条轨迹**。复位操作仅在数据记录关闭后执行。
4.  **动态难度调整**：若某光照条件下连续 10 次成功率 >90% 或 <5%，需微调物体初始位置（±3cm）或光源角度，确保成功率落在目标区间内。
5.  **元数据标注**：每条数据的 metadata 必须包含 `lighting: full/half/dark`、`success: bool`、`duration_s` 字段。

### 6.4 Q Critic 训练前 Sanity Check
正式进入阶段 C 前，必须验证 Q Critic 的有效性：
-   输入亮光成功轨迹 → Q 值应持续处于高位
-   输入暗光失败轨迹 → Q 值应快速衰减至低位
-   若两者 Q 值无显著差异，**禁止进入阶段 C**，需重新调整训练数据或超参

## 7. 阶段 C：Baseline vs QGF 对比实验

### 7.1 实验设计原则
采用 **3×2 全因子实验矩阵**，所有测试均使用 Baseline 模型作为策略主干，仅切换是否启用 Q-Critic Guidance。测试集与训练集**完全隔离**，且覆盖全部光照梯度。

### 7.2 3×2 实验矩阵

| 光照条件 \ 策略 | Baseline VLA (无 Guidance) | QGF (VLA + Q-Critic Guidance) |
| :--- | :--- | :--- |
| **亮光 (Full)** | 基准性能，预期 ~95% | 验证**不退化**，预期 ~95% |
| **中等光 (Half)** | 暴露弱点，预期 ~40% | 验证**显著提升**，预期 ~70-80% |
| **暗光 (Dark)** | 严重退化，预期 ~10% | 验证**OOD 鲁棒性**，预期 ~40-50% |

### 7.3 测试执行规范
1.  **样本量**：每个格子（共 6 组）至少完成 **20 次** 独立 rollout，总计 ≥120 次测试。
2.  **随机性控制**：每次 rollout 的物体初始位置在 ±3cm 范围内随机扰动，避免过拟合固定摆放。
3.  **超参冻结**：严格按照【2. 预注册并冻结的内容】执行，测试期间不得修改任何模型参数、Guidance 强度或阈值。
4.  **双盲评估**：成功/失败判定由未参与算法设计的操作员根据【3. 成功与失败定义】独立标注，避免主观偏差。

### 7.4 核心分析指标与可视化
-   **主结果**：分组成功率柱状图（X轴=光照，Y轴=成功率，双色对比 Baseline/QGF）
-   **过程分析**：Q 值随步数变化折线图（展示 QGF 在失败轨迹中的介入时机）
-   **统计检验**：对每组配对数据进行 McNemar 检验或 Bootstrap 置信区间，报告 p 值
-   **消融补充**（可选）：若资源允许，增加 “仅用亮光数据训练的 Critic” 作为消融组，证明混合光照训练集的必要性
